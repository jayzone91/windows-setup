# OneCommander Catppuccin Mocha Folder Icons

A Catppuccin Mocha/Mauve folder-icon pack mapped to OneCommander's built-in
FolderIcons naming scheme.

## Installation

Place or junction this directory as:

`%LOCALAPPDATA%\OneCommander\Resources\FolderIcons\CatppuccinMocha`

Then set:

`FolderIconsTheme = CatppuccinMocha`

## Design

The base folder shape is derived from Catppuccin's Papirus Folders
`folder-cat-mocha-mauve.svg`. Category overlays are custom SVG primitives built
for the OneCommander mapping.

Palette:
- Base #1E1E2E
- Mantle #181825
- Text #CDD6F4
- Mauve #CBA6F7
- Blue #89B4FA
- Green #A6E3A1
- Red #F38BA8
- Yellow #F9E2AF

Linux distribution icons use compact Catppuccin-colored badges instead of
copying third-party trademark artwork.
